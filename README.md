# WeWood Collection page (Bestsellers)

Static prototype of the WeWood collection template, built for the Noom (Boutique) Shopify theme. Everything is in `index.html`; images are in `assets/`.

Live: https://mohsufonit.github.io/wewood_cp/

Useful states: `?demo=real` (the 16 real products only), `?demo=soldout`, `?page=3`, and filter URLs such as `?filter.p.m.custom.colour=black&filter.v.on_sale=1`.

Deployed automatically to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
